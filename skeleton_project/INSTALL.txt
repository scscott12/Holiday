## 5) Tuning
- PIR: adjust hardware trimmer or MOTION_HOLD_SEC / MOTION_COOLDOWN_SEC envs.
- Listening: tune SPEECH_START_TIMEOUT, END_SILENCE_SEC, MAX_UTTERANCE_SEC, and ENERGY_GATE.
- Speech: Piper loads once at service startup and streams PCM directly to the output device.
- AUDIO_OUTPUT_DEVICE may be a sounddevice index or unique name substring; blank uses the system default.
- TTS_FRAME_MS=20 controls both PCM write and jaw-envelope resolution.
- TTS_CANNED_CACHE=1 pre-renders opening, goodbye, idle, and scene lines so canned speech avoids live synthesis.
- Ollama streams in the background while Piper speaks completed phrases.
- LLM_PHRASE_MIN_CHARS / SOFT_CHARS / MAX_CHARS tune natural phrase boundaries.
- Ollama uses /api/chat and remembers the latest LLM_MEMORY_TURNS exchanges for one visit.
- LLM_MEMORY_TURNS=3 and LLM_CONTEXT_TOKENS=512 are the recommended Pi defaults.
- Visit memory is cleared on goodbye/timeout and is never saved to disk.
- BARGE_IN_ENABLED=1 listens for command-only interruptions during streaming speech.
- "stop"/"quiet" end a visit; "wait" or BARGE_IN_WAKE_WORDS returns to listening.
- Raise BARGE_IN_ENERGY_GATE if speaker echo causes false interruptions.
- Set BARGE_IN_REQUIRE_WAKE_WORD=1 if bare commands are still too sensitive.
- Barge-in requires streaming Piper; legacy WAV mode reports legacy_tts and remains uninterrupted.
- IDLE_LIFE_ENABLED=1 adds sparse eye pulses, jaw twitches, and occasional mutters while motion is armed.
- IDLE_LIFE_MIN_SEC / MAX_SEC control cadence; IDLE_MUTTER_CHANCE controls how often an action speaks.
- Idle actions yield immediately to PIR, MQTT, shutdown, and barge-in. Legacy TTS safely skips mutters.
- SCENES_ENABLED=1 loads validated speech, pause, eye, jaw, and sound-cue sequences from SCENES_PATH.
- Copy uncompressed 16-bit PCM WAV cues below SCENE_SOUND_DIR and reference relative paths in scenes.json.
- SCENE_MAX_SECONDS=30 is a hard safety limit; PIR, MQTT, barge-in, and shutdown interrupt sooner.
- PERSONALITIES_ENABLED=1 loads validated character packs from PERSONALITIES_PATH.
- PERSONALITY=pirate chooses the first-run pack; Home Assistant can switch packs live while idle and the saved choice wins on later restarts.
- A pack changes prompts, canned lines, reply bounds, voice volume, barge-in words, idle mutters, and its default scene together.
- Pack switching is rejected while a visit, scene, speech, or idle behavior is active.
- PERSIST_SETTINGS_ENABLED=1 restores operator controls after service/Pi restarts.
- Only personality, switches, night mode, eye levels, and volume are saved; visitor speech and credentials are never written.
- The packaged service owns /var/lib/holiday-skeleton and writes the state file atomically with 0600 permissions.
- HEALTH_INTERVAL_SEC=30 publishes component health, Pi telemetry, and latency statistics without blocking audio.
- HEALTH_LATENCY_WINDOW=20 controls the recent-turn rolling average/P95 window.
- CPU temperature, disk use, current throttle flags, Piper availability, and Ollama are evaluated automatically.
- OLLAMA_HEALTHCHECK_ENABLED=0 disables the periodic /api/tags probe without disabling conversation replies.
- EYES_INVERT=1 if your LED driver is active-low.
- JAW_MIN_US/JAW_MAX_US to set jaw travel.
- Eyes Dim/Full % and Volume % are "number" controls in HA with box entry.
- Night mode reduces brightness & volume.
